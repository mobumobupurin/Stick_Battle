# アーケードUI（メニュー全面リニューアル）

格ゲー／アーケード筐体をテーマに、タイトルから対戦準備・オンライン・リザルトまでのメニュー画面を作り直した。

## 方針
- **見た目の指定は `src/styles/arcade.css` に集約**。各画面は `ax-screen` と `ax-*` クラスの新しいマークアップに置き換えたため、以前のCSSレイヤーのクラス指定はほぼ当たらない。ID指定で `!important` を使っている古いルールだけ、arcade.css 側で上書きしている。
- **JavaScriptが参照するIDはすべて維持**（`title-tap`, `go-*`, `char-grid`, `chars-next`, `stage-grid`, `lb-*`, `res-*` など）。ゲーム処理・通信は変更していない。
- 新規スクリプトは `src/game/29-arcade-ui.js` のみ（メニューのプレビュー切り替えと ▲▼ キー移動）。

## 画面
- **タイトル**：落ち着いたキーアート。暗い背景に、赤と青のリムライトで縁取ったシルエットの格闘家と剣士が一撃を交わす瞬間（`titleIllustration()` でコード描画、静止画）。左にロゴ（白＋赤の下線）、下に枠線だけの PRESS START（ゆっくり明滅するだけ）。点滅・光の流れ・走査線・流れる文字は使わない。縦長スマホではロゴを上、2人を中央に置く。
- **モード／チャレンジ／トーナメント**：左に斜めのメニューバー、右に選択中モードのイラスト付きプレビュー。900px以下はプレビューを省き、各項目に説明文を表示。
- **キャラ選択**：左に大きなショーケース（英字名の透かし、1P表示、区切り付きゲージ）、右に斜めタイルのロスター。下に名前とCPU設定。
- **ステージ選択**：大きなプレビュー＋ランダム3種＋ステージタイル、右にルールパネル。決定ボタンは「FIGHT!」。
- **オンライン入口**：HOST / JOIN の2枚パネル。ゲームHUB・大会モードで色が変わる。
- **ロビー**：招待（QR・ルームコード）／参加者／自分のキャラ／ルールの4パネル。
- **リザルト**：「GAME SET!」と放射線の背景、勝者の大きな立ち絵、順位カード。
- モード選択のプレビュー絵もタイトルと同じシルエット＋リムライトの絵柄。
- 技・キャラ解説ダイアログも同じ配色に統一。
- 目の負担を減らすため、ボタンの光の流れ・矢印の点滅・選択中カードの脈動・走査線はすべて止めている。
- 協力ボス・トーナメント表・ランキング・遊び方は内容を保ったまま見出し・ボタン・背景を統一。ゲームHUB画面は独自デザインを残し、背景のみ統一。

## 検証
- `npm run build` / `npm run check` / `npm test`（309件）成功。タイトル画面とモード順のテストは新デザインに合わせて更新。
- p5.js を読み込めない環境のため、描画関数をスタブにしたブラウザ（Chrome）で 1366×860 と 390×844 の各画面を撮影して確認。タイトル→モード→キャラ→ステージ→戻る、チャレンジ→トーナメント→戻る、オンライン入口→戻る、をクリック操作で確認。
- 対戦画面（キャンバス描画・HUD）は今回変更していない。実機スマホ・実オンライン接続での確認は未実施。
